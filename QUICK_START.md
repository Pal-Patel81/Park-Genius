## 🐛 If Something Breaks

**"API not responding"**
→ Make sure `python parkgenius_api.py` is running in a terminal

**"Module not found"**
→ Re-run: `pip install flask flask-cors flask-socketio pandas numpy scikit-learn`

**"Port already in use"**
→ Kill other Python processes or change port in `parkgenius_api.py` line 434
